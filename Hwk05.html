The three rankings reveal very different patterns of COVID burden across US counties.

Ranked by cases per population, small counties with large institutional populations top the list: prisons (Trousdale, TN; Norton, KS) and military bases (Chattahoochee, GA) explain the extreme rates, as these dense enclosed environments drive rapid transmission regardless of county size.

Ranked by deaths per population, a different set of small rural counties appears (Gove, KS; Jerauld, SD; Hancock, GA), likely reflecting older and more vulnerable local populations where fatality rates ran high even with fewer total cases.

The senior population ranking required filtering out counties with zero seniors recorded, which produced Inf values from division by zero. Once cleaned, this ranking surfaces Native American reservation counties (McKinley, NM; Big Horn, MT) and urban areas like the Bronx, NY, pointing to the disproportionate COVID toll on those communities.

No single metric tells the full story. The rankings diverge significantly depending on which dimension of burden is measured, which is exactly why looking at all three together matters.

Question 3 - Box Plots

Sepal width - base R

# Base R box plot of sepal width as instructed
boxplot(iris$Sepal.Width,
        main = "Sepal Width",
        ylab = "Width (cm)")

# Vertical orientation is cleaner for a single variable
ggplot(iris, aes(y = Sepal.Length)) +
  geom_boxplot() +
  labs(title = "Sepal Length",
       y = "Length (cm)") +
  theme(axis.text.x = element_blank(),
        axis.ticks.x = element_blank())

Sepal length across all iris observations has a median around 5.8 cm with the middle 50% of values falling between roughly 5.1 and 6.4 cm. The distribution is fairly symmetric with no obvious outliers, and the whiskers extend from about 4.3 to 7.9 cm.

Petal length vs class - ggplot

# Notched box plot of petal length by species, colored by species
ggplot(iris, aes(x = Species, y = Petal.Length, fill = Species)) +
  geom_boxplot(notch = TRUE) +
  labs(title = "Petal Length by Species",
       x = "Species",
       y = "Petal Length (cm)") +
  theme(legend.position = "none")

Petal length differs dramatically across the three species. Setosa has by far the shortest petals (median around 1.5 cm) with very little variation, while versicolor sits in the middle (median around 4.3 cm) and virginica has the longest petals (median around 5.6 cm). The notches on all three boxes do not overlap, which indicates the medians are statistically significantly different from each other. Setosa also shows two outliers, and its very tight IQR suggests it is the most consistent of the three species in petal length.

Petal width vs class - strip, jitter and violin

# Strip plot
ggplot(iris, aes(x = Species, y = Petal.Width, color = Species)) +

# Violin plot
ggplot(iris, aes(x = Species, y = Petal.Width, fill = Species)) +

       x = "Species", y = "Petal Width (cm)") +

The jitter and violin plots tell the same story as the petal length analysis. Setosa stands out immediately with petals clustered tightly at around 0.2 cm — the jitter plot especially shows just how little variation there is across all 50 observations. Versicolor sits in the middle with values centered around 1.3 cm, and virginica has the widest petals, spreading mostly between 1.5 and 2.5 cm. The violin shapes are worth noting too: setosa looks almost flat and pancake-like because nearly all its values land at the same point, while virginica stretches tall showing more range in the data.

Question 4 - Histograms

Sepal width - base R

# Base R frequency histogram of sepal width as instructed
hist(iris$Sepal.Width,
     main = "Sepal Width Distribution",
     xlab = "Sepal Width (cm)",
     col  = "steelblue")

Sepal width is centered around 3.0 cm and has a pretty classic bell shape, ranging from about 2.0 to 4.4 cm. The tallest bar lands right at 3.0 with around 35 observations. There is a slight right skew with a longer tail on the upper end, but overall the distribution is fairly symmetric.

Sepal length - ggplot frequency histogram + polygon

# Part 1: Frequency histogram
# binwidth = 0.2 is the smallest that avoids empty bins
ggplot(iris, aes(x = Sepal.Length)) +
  geom_histogram(binwidth = 0.2, fill = "steelblue", color = "white") +
  labs(title = "Sepal Length Frequency Histogram",
       x = "Sepal Length (cm)",
       y = "Count")

# Part 2: Frequency polygon overlaid on histogram
ggplot(iris, aes(x = Sepal.Length)) +
  geom_histogram(binwidth = 0.2, fill = "steelblue", color = "white") +
  geom_freqpoly(binwidth = 0.2, color = "red", linewidth = 1) +
  labs(title = "Sepal Length with Frequency Polygon",
       x = "Sepal Length (cm)",
       y = "Count")

Sepal length ranges from about 4.3 to 7.9 cm with the tallest bar landing at 5.0 cm. Rather than one clean peak, the distribution has two humps, which makes sense given that the three species have quite different sepal lengths pulling the overall shape apart. The frequency polygon traces that pattern nicely, making the rises and dips between bins easier to follow at a glance.

Petal length - density histogram + kernel density

# Part 1: Density histogram
# binwidth = 0.2 is the smallest that avoids empty bins
ggplot(iris, aes(x = Petal.Length)) +
  geom_histogram(aes(y = after_stat(density)),
                 binwidth = 0.2, fill = "steelblue", color = "white") +
  labs(title = "Petal Length Density Histogram",
       x = "Petal Length (cm)",
       y = "Density")

# Part 2: Kernel density estimator overlaid
ggplot(iris, aes(x = Petal.Length)) +
  geom_histogram(aes(y = after_stat(density)),
                 binwidth = 0.2, fill = "steelblue", color = "white") +
  geom_density(color = "red", linewidth = 1) +
  labs(title = "Petal Length Density with KDE",
       x = "Petal Length (cm)",
       y = "Density")

Petal length has a very clear two-humped shape, a tall narrow spike around 1.0 to 1.5 cm and a broader second hump stretching from about 3.5 to 6.5 cm. That gap in the middle is setosa completely separated from the other two species. The KDE line smooths over the bin-by-bin noise and makes the bimodal structure even more obvious, though it undersells the height of the setosa spike since it is spreading the density across a wider range than the actual data.

Petal width by class - faceted histogram + polygon

# Part 1: Faceted frequency histogram, vertical orientation
ggplot(iris, aes(x = Petal.Width, fill = Species)) +
  geom_histogram(binwidth = 0.2, color = "white") +
  facet_wrap(~ Species, ncol = 1) +
  labs(title = "Petal Width by Species (Faceted Histogram)",
       x = "Petal Width (cm)",
       y = "Count") +
  theme(legend.position = "none")

# Part 2: Faceted frequency polygon
ggplot(iris, aes(x = Petal.Width, color = Species)) +
  geom_freqpoly(binwidth = 0.2, linewidth = 1) +
  facet_wrap(~ Species, ncol = 1) +
  labs(title = "Petal Width by Species (Faceted Frequency Polygon)",
       x = "Petal Width (cm)",
       y = "Count") +
  theme(legend.position = "none")

Breaking petal width out by species makes the differences really obvious. Setosa spikes sharply right at 0.2 cm and drops off almost immediately, confirming how tightly packed its values are. Versicolor has a much smoother, wider curve centered around 1.3 cm with a fairly even spread on both sides. Virginica is the most spread out of the three, with values running from about 1.4 to 2.5 cm and a flatter peak around 2.0 cm. The faceted layout makes it easy to compare the shapes side by side without the species overlapping and cluttering each other.
